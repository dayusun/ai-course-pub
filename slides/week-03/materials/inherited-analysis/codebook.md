# Codebook: sleep and mood survey (synthetic)

Invented data; no real participants. 412 respondents, one row each.

| Variable | Meaning | Values |
|---|---|---|
| id | respondent identifier | R001-R412 |
| age | age in years | 18-80 |
| sex | sex | F, M |
| smoker | current smoker | 1 = yes, 0 = no |
| phq9 | PHQ-9 depression score | 0-27; 10 or more = moderate or worse |
| sleep_hours | usual sleep per night | hours; **-99 = did not answer** |
| income_band | household income band | 1-5; NA = did not answer. Not used in Table 1. |
