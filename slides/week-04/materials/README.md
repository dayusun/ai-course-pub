# Week 4 hands-on folders

All data are synthetic. The slides have every step with the prompts to copy; each folder's
README has the same steps for when you continue after class.

## The running project

| Folder | Part | What you do |
|---|---|---|
| `glucose-trial/` | 1-5, 7-9 | set up an analysis project, profile and clean the data, plan and run the analysis, Figure 1 and a flow diagram, sample size, a cluster job script, the record and a rerun |
| `coauthor-check/` | 6 | a co-author's analysis of the same trial, reviewed in a new OpenCode session |

## More practice

| Folder | What you practise |
|---|---|
| `fix-a-figure/` | a bar chart with three planted errors: find them against `figure-source.csv`, have the agent fix `plot_figure.py`, check every value |
| `walking-trial/` | October's worked example: a 300-patient trial, plain prompt vs `AGENTS.md`, and an event rate whose denominator is your decision |
| `~/week-03/inherited-analysis/` | from Week 3: an inherited R script gives N = 368, the manuscript says 412; find why, fix it in a copy |
| your own project | the setup of Part 1 on a copy of your own work, with **no protected data** on the hub |

Start each in its own folder: `cd ~/week-04/<folder>`, `git init`, `opencode`.
